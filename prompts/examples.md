# Example requests

## Executive review

```text
Create a 6-slide executive supply-chain review for ABNAH for January 2026.
Include net sales, reported margin, consumption variance, month-end inventory
exposure, open-PO liability, outlet comparison, menu items at risk, and a
prioritized action plan. Use exact Zoho data and clearly label period totals
versus 31 January positions.
```

## Outlet comparison

```text
Compare ABNAH outlets for the latest completed month. Rank them by sales,
margin, inventory exposure, overdue procurement, and consumption leakage.
Create an editable PowerPoint with one executive summary slide and one detailed
outlet scorecard slide.
```

## Menu risk

```text
Create a management presentation showing the top menu items at risk for the
latest valid snapshot. Trace each menu item to critical ingredients, available
stock, forecast demand, shortage, monetary exposure, outlet, and required
action. Do not combine amber and red risk without labeling severity.
```

## Data-quality review

```text
Build a short data-quality review for ABNAH. Show exceptions by rule, source
table, outlet, and item; explain business impact; and separate static mapping
issues from dated transaction exceptions.
```

## Refining a deck

```text
Revise the last deck for a CFO audience. Reduce operational detail, retain all
material caveats, lead with financial exposure, and add an owner and deadline
to every action. Keep the deck fully editable.
```
